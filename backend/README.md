# Growth Tracker — Backend (FastAPI + SQLAlchemy)

## Local setup

```bash
python3 -m venv venv
source venv/bin/activate        # on Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

API runs at http://localhost:8000
Interactive docs (auto-generated by FastAPI): http://localhost:8000/docs

By default this uses a local SQLite file (`dev.db`) so you can start
building immediately with zero setup. Nothing to install for that —
it's built into Python.

## Switching to MySQL

1. Install MySQL locally (or use a free MySQL instance on Railway).
2. Create a database: `CREATE DATABASE growth_tracker;`
3. Copy `.env.example` to `.env` and fill in your real credentials:
   ```
   DATABASE_URL=mysql+pymysql://root:yourpassword@localhost:3306/growth_tracker
   ```
4. Restart the server — tables are created automatically on startup,
   and the default quests are seeded the first time.

## Project structure

```
app/
  database.py    — SQLAlchemy engine/session setup
  models.py      — ORM models (the actual tables)
  schemas.py     — Pydantic request/response validation
  crud.py        — database read/write functions
  game_logic.py  — XP, rank, streak, coin and milestone rules
  seed_data.py   — default quest templates
  main.py        — FastAPI routes (the API itself)
```
